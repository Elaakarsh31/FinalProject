# GPT-Style Shakespeare Text Generator

A decoder-only Transformer, built from scratch in PyTorch, that generates Shakespeare-style
text one character at a time. Trained on the Tiny Shakespeare dataset and benchmarked against
a bigram baseline to measure how much self-attention actually contributes.

**Team:** Aakarsh Arora, Noah Caney

**Full written report:** `Final_Report.docx` (Iteration 5 final report — abstract, EDA,
model details, evaluation, ablation studies, discussion, and conclusions)

## Overview

This project implements a GPT-style language model (token + positional embeddings, masked
multi-head self-attention, feed-forward blocks with residual connections and layer
normalization) and trains it to predict the next character in a sequence. A simple bigram
model is included as a baseline for comparison.

Next-character prediction is treated as what it actually is: a multi-class classification
problem over the character vocabulary. That means standard classification metrics (accuracy,
precision/recall/F1, confusion matrix) apply directly, alongside perplexity, the standard
metric for language models.

## Dataset

- **Source:** Tiny Shakespeare (Andrej Karpathy's char-rnn dataset), ~1.1 million characters
  of Shakespeare's collected plays.
- **Tokenization:** character-level; every unique character in the corpus is one token.
- **Split:** 90% train / 10% validation.

## Setup

```bash
git clone https://github.com/Elaakarsh31/FinalProject.git
cd FinalProject
pip install -r requirements.txt
```

Download the Tiny Shakespeare dataset and place it as `input.txt` in the project root:

```bash
curl -o input.txt https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt
```

## Usage

**Run the exploratory data analysis** (corpus statistics and character frequency plot; does
not require a trained model or even PyTorch):

```bash
python src/eda.py
```

**Train (or load) the main model and generate text:**

```bash
python main.py
```

Trains a new model if none is saved yet, then generates a 1000-character sample.

**Run the full Iteration 4 pipeline** (baseline comparison, hyperparameter search,
evaluation metrics, feature-importance ablations, and all plots):

```bash
python main.py
```

Iteration counts at the top of `main.py` are set low by default so the whole
pipeline finishes in a few minutes on a laptop (CPU or Apple Silicon MPS). Increase
`FINAL_ITERS` for better final numbers if you have more compute time available; the
architecture and evaluation code stay the same either way.

## Model Architecture

| Hyperparameter | Value |
|---|---|
| Embedding dimension | 384 |
| Attention heads | 4 (best from grid search; see report) |
| Transformer layers | 4 (best from grid search; see report) |
| Block size (context window) | 256 |
| Batch size | 64 |
| Dropout | 0.1 (best from grid search; see report) |
| Optimizer | AdamW, lr = 3e-4 |

## Results

Bigram baseline vs. tuned GPT Transformer on the held-out validation set:

| Metric | Bigram | GPT |
|---|---|---|
| Accuracy | 0.269 | 0.566 |
| Top-5 accuracy | 0.654 | 0.855 |
| F1 (macro) | 0.076 | 0.366 |
| Perplexity | 12.07 | 4.56 |

Self-attention roughly doubles next-character accuracy and cuts perplexity by more than half
compared to the no-context baseline. A context-length ablation further shows that most of
this gain comes from the first ~32 characters of history, with diminishing returns out to the
full 256-character window — see `results/context_ablation.png` and the project report for the
full breakdown.

Sample output after training:

> You look'd the day in banish'd; But now to oath by, there hath bridegrow Your curries
> heard air do slaughter to you. Lord: Madam, stand well, thriving it, and flesh all thears...
> KING RICHARD II: Say, my lord? where we'er in the rock

## Limitations

- Trained on a relatively small corpus (~1.1M characters) compared to modern language models.
- Character-level tokenization means the model spends capacity learning to spell rather than
  reasoning about words as units, which caps how coherent generated text can get at this scale.
