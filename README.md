# 🎭 GPT-2 Shakespeare Text Generator

A character-level language model built from scratch using PyTorch, modeled after the GPT-2 architecture, and trained on the works of William Shakespeare. The model learns to generate Shakespearean-style dialogue, vocabulary, and script structures entirely from scratch.

---

## 📊 Model Scale & Parameter Count

The model has a lightweight yet deep architecture designed to train efficiently on modern hardware (optimized for Apple Silicon / MPS and CUDA).

* **Total Trainable Parameters:** `0.004481 M` (~4.5 Million parameters)
